## 3. 検証テスト（閉形式・契約）

| テスト | 期待値の根拠 |
|---|---|
| 水 μ/ρ(60 keV) | XCOM 参照値 0.2059 cm²/g（テスト内に式・許容差を記述） |
| ヨード K エッジ | 33 keV と 34 keV で μ/ρ が 2 倍以上跳ねる（K エッジ 33.2 keV） |
| 単色・無ノイズの水回復 | 密度 1.0 g/cm³ を相対誤差 2% 以内で回復（FBP 誤差を許容） |
| 単色・無ノイズのヨード回復 | 公称濃度を相対誤差 3% 以内で回復 |
| 水中 HU | 単色分解は HU=0 が厳密。許容 ±10 HU は FBP リップルのみ |
| ヨード HU の式一致 | HU(E) = 1000·b·μ_i(E)/μ_w(E) を 5% 以内 |
| K エッジ単調性 | ヨード挿入部の HU が 40–190 keV で単調減少 |
| ビームハードニング | 120 kVp 多色 EID（1 ビン）で中心 HU < 周辺 HU − 3 HU（杯化の符号確認） |
| 決定論 | 同一 seed 2 回の回収でカウント一致（ビット一致＋sha256 一致）、異 seed で不一致 |
| 退化入力 | N0 < 100 や負の密度は ValueError（NaN や静かな 0 を返さない） |

### 測定済みの物理特性（2026-10-09、凍結構成で記録）

- 2 ビン分解行列の条件数 cond(M) ≈ 138（120 kVp・8 mm Al・閾値 30 keV）。
  2 ビン水/ヨード分解は不良条件であり、ヨード定量には実効エネルギー線形化由来の
  系統バイアス（凍結構成で約 −13%）が乗る。これは本研究の定量精度（H2）の
  一部として報告する量であり、テストの許容バンド（±25%）で隠蔽しない。
- 120 kVp 多色 1 ビン（EID 相当）の 20 cm 水ではビームハードニング杯化が
  中心で負の HU として観測される（符号テスト済み）。
